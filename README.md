# SmartGuard

Profesyonel akıllı güvenlik ve alarm mobil uygulaması (iOS & Android).

## Özellikler (UI)

- Material 3 + koyu tema (varsayılan)
- Splash, Ana Sayfa, Alarmlar, Geçmiş, Ayarlar
- Alt navigasyon
- Responsive, animasyonlu arayüz

> Bluetooth, ESP32, RTC ve alarm mantığı sonraki aşamada eklenecek. Şu an yalnızca profesyonel UI.
